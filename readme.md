# Many web design choices of the post 2000s era irritate me significantly, especially the constant pushes of useless features used to appease the senseless public instead of actually doing anything novel. I made this series of tampermonkey scripts to remove this degenerate bloat from my client, as well as general annoyances especially concerned with web based chat app features designed to grab your attention 24/7. This is my attempt at fixing this world. Here's the list of my fixes:
## General
### freeze-favicon.js - Freezes website favicons upon initial load so you don't see any annoying favicon updates 
## Google
### remove-gemin-from-docs.js - Removes gemini integration from Google docs
### remove-google-oauth-popups.js - Removes the popup you get prompting you to sign in with Google when you visit a site
## Discord
### make-pings-grey.js - Makes both ping badges and ping message highlights grey
### remove-shop-and-quests.js - Removes the shop and quests from the DMs tab
